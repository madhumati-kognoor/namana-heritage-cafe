# Namana Heritage Cafe

## Project Overview

A premium, responsive food-ordering landing page created as part of a Frontend Development Internship Week 1 project.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS animations and transitions
- Responsive Web Design

## Features

- Premium responsive navigation
- Editorial hero section
- Four food categories
- Nine menu items with INR prices
- Special offer section
- Why Choose Us feature blocks
- About section
- Contact information and labeled demonstration form
- Responsive footer
- Subtle hover interactions and entrance animations
- Keyboard focus styling and reduced-motion support

## Week 1 Scope

Week 1 focuses on semantic HTML, CSS styling, responsive design, Flexbox, CSS Grid, animations, transitions, and accessibility basics. The ordering and cart controls are visual only; JavaScript functionality is planned for a later phase.

## Repository Description

Premium responsive heritage-inspired food ordering landing page built with HTML5 and CSS3.
